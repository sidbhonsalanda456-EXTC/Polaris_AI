## Overview

This project is the AI/ML module for the Smart Energy Management System for Polar Research Stations.
It predicts weather conditions, renewable energy generation (solar and wind), and station energy demand using machine learning models.

The predictions generated by this module are used by the Energy Optimization team to make allocation and scheduling decisions.

## What This Module Does

- Fetches live polar weather data from the station weather network / Open-Meteo API
- Reconstructs a realistic 1-year hourly historical dataset from station telemetry
- Trains 3 Random Forest models: Solar, Wind, and Demand prediction
- Produces 24-hour forecasts for all energy resources
- Monitors weather and disaster risk alerts
- Generates Matplotlib/Seaborn visualizations
- Serves a dark-themed web dashboard
- Outputs JSON forecast data for the Energy Optimization team

## What This Module Does NOT Do

- Energy optimization or load scheduling
- Battery charging/discharging decisions
- Diesel generator control
- CHP control
- Final optimal decision-making

## How to Run

### 1. Install packages

```bash
pip install -r requirements.txt
```

### 2. Generate the historical dataset

```bash
python data_generator.py
```

This creates `data/historical_weather_energy.csv` with one year of realistic hourly polar weather and energy data.

### 3. Train the ML models

```bash
python train_models.py
```

This trains three Random Forest Regressor models and saves them as `.pkl` files in the `models/` directory.

### 4. Run the AI/ML application

```bash
python app.py
```

Open http://localhost:5000 in your browser to access the dashboard.

The application will:
- Fetch live weather data from the station weather network
- Predict solar, wind, and demand for the next 24 hours
- Generate weather and disaster risk alerts
- Save forecast data to `output/ai_forecast.json`
- Generate charts in `output/charts/`
- Display the web dashboard

## Models

### Solar Prediction
- **Algorithm:** Random Forest Regressor (200 trees)
- **Features:** Solar irradiance, cloud cover, temperature, snowfall, hour, month, season
- **Output:** Predicted Solar PV power in kW (0-300 kW)

### Wind Prediction
- **Algorithm:** Random Forest Regressor (200 trees)
- **Features:** Wind speed, direction (sin/cos), temperature, pressure, snowfall, hour
- **Output:** Predicted wind power in kW (0-300 kW)

### Demand Prediction
- **Algorithm:** Random Forest Regressor (200 trees)
- **Features:** Temperature, feels-like, hour, day of week, month, snowfall, weather severity, previous demand
- **Output:** Predicted station demand in kW

## Evaluation Metrics

- **MAE (Mean Absolute Error):** Average prediction error
- **RMSE (Root Mean Squared Error):** Penalizes large errors more
- **R² Score:** How well predictions match actual values (1.0 = perfect)

## Risk Alerts

The system monitors for:
- Cloud cover > 80% (low solar risk)
- Low solar irradiance (solar generation risk)
- Wind speed < 3 m/s (low wind risk)
- Wind speed > 25 m/s (turbine shutdown risk)
- Heavy snowfall (panel performance risk)
- Extreme cold (heating demand increase)
- Scheduled fault windows (wind, hydro, diesel maintenance)
- Disaster windows (flood, storm, tsunami)
